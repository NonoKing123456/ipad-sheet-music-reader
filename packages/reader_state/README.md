# reader_state

Windows / iPad 共用的纯 Dart 阅读状态：笔迹、文字、曲单、阅读位置、持久化及设备间合并。本包不打开或修改 PDF / 图片，也不处理界面手势。

## 主要约定

- 批注按条目、内容版本、页码关联，使用页面归一化坐标。
- 编辑操作等待持久保存成功；失败不得向界面报告已保存。
- 撤销重做属于会话历史，重新加载或合并后可能重置。
- 曲单支持重复曲谱，每次出现以独立条目 ID 区分。
- 导航可跨曲，首尾不循环；缺失、旧版本及等待元数据是不同结果。
- 持久状态使用临时提交、备份和并发控制，不直接覆盖其他实例的较新状态。
- 合并保留同对象冲突的完整版本，不按时间戳简单覆盖。
- 模型包含文字和图层等后续扩展，实际 schema 与兼容规则以代码为准。

入口为 `lib/reader_state.dart`，集成关系见 [架构说明](../../docs/ARCHITECTURE.md)。

## 开发

```sh
dart pub get
dart analyze
dart test
```

在本目录运行，测试使用临时状态，不读取私人批注或曲单。
