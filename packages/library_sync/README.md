# library_sync

纯 Dart 局域网同步层，负责配对认证、目录与内容传输、离线副本、阅读状态合并，以及设备签名状态报告。扫码界面、平台权限和自动连接设置属于 Flutter 应用层。

## 主要约定

- HTTP 私有局域网传输不提供 TLS 加密，不应暴露到公网。
- 临时配对码两分钟单次有效，后续请求使用 Bearer 凭据。
- 每台设备独立配对，不复制客户端凭据来生成新设备。
- 目录同步与选择性内容下载分开，可见条目不一定离线可读。
- 内容使用受控私有路径，传输校验长度与 SHA-256，不信任对端逻辑路径。
- 提交清单前核验文件，失败保留最后提交状态；重试复用完整对象。
- 普通打开可复用核验元数据，显式完整校验重新读取文件。
- 状态合并使用共同基线和持久事务记录，冲突保留完整版本。
- 签名报告是最近接收的历史状态，不证明实时在线或续签成功。

入口为 `lib/library_sync.dart`。整体协议边界见 [架构说明](../../docs/ARCHITECTURE.md)，网络限制见 [安全说明](../../SECURITY.md)。

## 开发

在本目录执行：

```sh
dart pub get
dart analyze
dart test --reporter expanded
```

测试使用临时文件与回环连接。回环测试不证明真实 iPad 权限、Wi-Fi 性能或后台行为。
