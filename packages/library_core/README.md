# library_core

曲谱阅读器的纯 Dart 只读文件索引，负责目录扫描、稳定条目身份、内容版本、搜索和索引恢复，不渲染曲谱或改写原文件。

## 主要约定

- 支持 PDF、JPG / JPEG、PNG、WebP，保留目录层级与独立条目。
- 本机绝对路径不作为跨设备 ID，便携相对路径使用 `/`。
- 内容相同的不同文件不直接合并；移动推断存在歧义时保留信息。
- 批注应同时关联条目 ID 与内容版本，不能只按文件名或哈希关联。
- 普通扫描复用未变元数据，`verifyAll` 重新读取内容。
- 索引与备份放在源目录之外，缺失与不可读状态需由界面展示。
- 版本历史记录元数据，不保存每一版原文件字节，不能代替原谱备份。

入口为 `lib/library_core.dart`，集成关系见 [架构说明](../../docs/ARCHITECTURE.md)。

## 开发

在本目录执行：

```sh
dart pub get
dart analyze
dart test
```

测试使用临时合成谱库，不依赖真实用户曲谱。
