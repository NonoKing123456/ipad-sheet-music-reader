# 使用指南

[返回首页](../README.md) · [常见问题](FAQ.md)

Windows `+33` 已交付，唯一构建114.2秒，19成员与share-v1发布校验通过，固定入口及任务栏身份保持；根 iPad `+33` 包已核并交付（唯一 Intel run24，编译源 `a9a84fdd`），原生设备目标仍为arm64。原生烟测与完整包校验通过，用户仍需自行安装确认；这不代替真实装机、后台、网络速度和系统分享验收。

## +33 更新操作

- 路径显示由实际宽度决定：宽处即使八层或更多也完整显示；仅空间不足时才折叠所需中间目录。根、最近父目录和当前优先保留，窄处文字省略可查看完整 Tooltip，菜单中的每项仍对应原完整路径。返回上级按钮单独48×48，当前目录只是当前位置文字。
- 电脑双页可直接点“批注”，两页保持同屏，不弹左右页选择。再选画笔、荧光笔、橡皮或文字，在哪一页落下就操作哪页；中间空隙不落笔。文字草稿的提交/取消保护与退出、保存、撤销规则保持。

## +32 更新操作

- 搜索在外观按钮左边。点击太阳/月亮直接切到另一种明暗外观并保存；首次未选择时跟随系统，不再弹出外观菜单。
- 中央呼出阅读工具栏后，即使未选工具，也可单指上下拖动查看被顶部栏遮住的谱面；只提供真实遮挡所需空间，收起工具栏恢复位置。没有工具时的横滑翻页、已选工具时的单指批注及双指移动缩放保持。
- 谱库颜色、字号、圆角及间距按设计令牌更新，操作结构保持。暗色仅改变应用外壳，谱面保持原色；白纸上的光标、选区和错误提示仍保持适合纸面的深色对比。
- 新旧两端协商后，单个小文件上限为1 MiB，每批仍最多64件 / 4 MiB、系统任务最多6个。批量准备只处理所选文件并合并目录提交；旧服务仍按256 KiB或单文件路径工作，大文件路径保持。Windows合成测量不是iPad、局域网或后台下载速度保证。

## +31 现有操作

- 阅读工具默认不选中；中央点按只收起或显示工具栏。每个工具再次点击可取消，没有工具时单指阅读、翻页或拖动。明确选画笔、荧光笔、橡皮或文字后，单指、鼠标或笔操作相应工具；双指仍可移动和缩放，第二指会取消尚未保存的指画整条笔迹。笔输入优先，避免同时手指误画。
- iPad 时间、电量和 Wi-Fi 状态区不随阅读工具收起而隐藏。顶部已移除缩小、整页和放大三个按钮；保留双指、Ctrl＋滚轮及既有缩放手势，不新增替代按钮。
- 新文字真正以空白一行开始，空白退出不留记录。单击已有文字只选择，双击进入原位输入；正在输入时的双击仍由系统处理选词。T 与其他工具共用固定顶部样式，吸色器和颜色入口保留；文字删除在框旁红色垃圾桶，不另加顶部编辑或删除按钮。三个移动、旋转缩放及换行宽度控制点继续保留。
- 点输入框外保存，成功后收键盘并恢复临时避让视图；切工具、离开和分享也先保存，失败保留草稿。色板、输入法、正文及控制点操作不触发误保存。原有短框、手动宽度、撤销及横纵旋转吸附规则保持。
- 外观默认跟随系统；点击太阳/月亮一键切换明暗并持久保存，提示文字说明将切换的模式。深色保留曲谱原色，谱面外空隙和系统状态区统一纯黑；工具栏使用深色界面。
- 分享先选择“原文件”或“带批注的 PDF 副本”。原文件保留格式及字节；批注副本逐页合成图像化 PDF，文字不再保证可搜索，可能更大。可取消导出，原谱不会被覆盖。
- 小文件微批按能力协商：新端每件不超过1 MiB，旧服务仍为256 KiB；每批最多64件 / 4 MiB；大文件或旧电脑服务使用原传输路径。系统调度仍受 iPadOS 限制，Windows 合成请求数减少不能证明 iPad 速度或息屏行为。

## 1. 准备电脑谱库

Windows 阅读器中选择“添加谱库文件夹”。支持多个独立来源，保留原有层级，无需把曲谱搬到同一个目录。

支持 PDF、JPG / JPEG、PNG 和 WebP。每张图片是一份单页曲谱；同目录中的多张图片不会自动变成多页 PDF。

- 点击文件夹进入下一层，使用路径导航返回上层。
- 点击搜索或按 `Ctrl + F`，按文件名、文件夹和路径查找；可只搜索当前文件夹及子文件夹。
- 普通刷新更新目录；“完整校验此谱库内容”重新读取内容，大谱库耗时更长。
- 云盘中的文件应先实际下载到电脑，占位文件不能当作已经准备好的曲谱。
- Windows 列表支持打开文件所在目录，方便在资源管理器中定位原谱。

应用不修改原谱。移动、覆盖或删除源文件可能改变可用状态，先保存编辑并保留备份。

## 2. 首次连接 iPad

1. 两台设备连接同一可信局域网，电脑也可通过同一路由器的有线网络连接。
2. 电脑打开“连接我的 iPad”，显示连接二维码。
3. iPad 选择“扫描电脑二维码”，允许相机权限。
4. 首次连接允许“本地网络”权限。
5. 配对成功后应用记住电脑，后续通常无需每次重新扫描。

二维码是应用自己的配对数据，不是普通网页链接。8 位临时码单次使用、两分钟有效，过期或失败后在电脑更新二维码再试。两台设备的系统时间应准确。

电脑换网络或地址变化时可重新扫描。高级连接信息支持手动填写地址与配对码；`127.0.0.1` 仅指当前设备，不能用于 iPad 连接另一台电脑。

“下次打开阅读器，自动连接我的 iPad”为可选设置。更新或下载时仍需电脑应用运行、源谱可读、网络连通。

## 3. 选择离线内容

配对后更新目录，再选择下载：

- 单份曲谱：曲谱旁的离线选项 → “下载到 iPad”。
- 整个文件夹：文件夹选项 → 下载此文件夹，也可选择下载整个谱库。
- 后续更新：顶部“更新目录”只获取目录元数据，不重新启动下载；需要下载新内容时，在曲谱、文件夹或同步管理中操作。
- 空间管理：“取消离线选择”管理选择状态；“移除本机下载”移除本机文件。两者不同，都不会删除电脑原谱。

图标区分未下载、部分下载、已下载等状态。**目录可见不代表离线可读。** 演出前实际打开曲单中的每首曲谱，确认页面完整。

顶部状态入口可进入同步管理，查看任务并暂停或继续下载。忙碌时只显示一个进度指示；重复的三点菜单和曲单入口已精简，曲单仍从页面保留的“曲单”入口进入。文件数达到总数时可能仍在校验或保存清单，请等待完成提示。

`0.8.10+28` 使用 iPad 系统后台队列处理下载，切换应用或息屏后可继续传输，实际调度由系统决定。电脑应用仍须运行且网络可达；手动从多任务界面强制划掉应用会取消系统传输，重新打开后再继续。暂停、中断或重开后保留已完成且通过校验的文件；当前电脑服务不支持 Range，当前未完成文件在缺少可用续传数据时可能需要重新下载。上述后台、息屏和恢复行为仍待真机验证。

## 4. 阅读与翻页

电脑支持单页、双页、连续模式；iPad 以适合实际屏幕的整页阅读为主要入口。

| 输入 | 常用行为 |
| --- | --- |
| 页面左侧 35% / 右侧 35% | 上一页 / 下一页 |
| 中间区域 | 显示或收起工具 |
| 未放大时水平滑动 | 翻页 |
| 双指缩放 | 放大、缩小 |
| 放大后拖动 | 查看页面其他区域 |
| `Page Up` / `Page Down` | 单次翻页，忽略长按重复 |

批注、文字编辑、阅读锁定和不同布局可能接管手势。输入文字时，翻页快捷键不会抢占文字编辑。

单份曲谱首末页不循环。使用页码定位工具可快速跳到目标页。脚踏若发送标准翻页键，可使用同一输入入口，实际兼容性需在自己的设备上验证。

**`0.8.10+30` 打开曲谱候选：** 从目录、搜索结果或直接打开曲谱开始新阅读会话时，默认从第 1 页开始，不再自动跳回上次读到的页。明确指定的打开页码、历史入口指定页、页码定位仍按指定位置打开；曲单向上一首进入末页、向下一首进入首页的规则保持。此调整不清除原有批注、曲单或阅读记录。

## 5. 批注

从谱库打开曲谱后进入批注工具，选择画笔、荧光笔、橡皮或文字工具，设置颜色与画笔粗细；文字大小和角度通过框旁联合控制点调整。撤销和重做属于当前编辑历史，重新打开或合并其他设备编辑后可能重置。

选择文字工具后，点谱面上的目标位置即可原位输入；选择已有文字可再次编辑。输入时谱面保持可见，不另设字号输入框。较早的 `+27` / `+28` 使用顶部 `×` 取消、`✓` 完成；下面是已交付 `+29` 的文字操作，实际 iPad 键盘仍待真机确认。

**`0.8.10+29` 文字操作：** 移除字体选择入口，顶部色板持续可见，选择的颜色作用于当前草稿或选中的文字。单指或鼠标主键点文字框外的谱面即可保存，包括点双页布局的另一页；保存成功后收起键盘并恢复因键盘避让临时调整的阅读视图。这一次点击只结束编辑，不翻页，也不新建第二个文字框。

色板、文本输入区、输入法候选和控制点的操作，以及拖动或双指缩放，不应触发上述点击保存。切换工具、退出批注或返回上层时先等待保存，失败则保留编辑并阻止离开。空的新草稿不保留为批注，内容未变不增加撤销记录。旧批注的字体数据及显示兼容继续保留，此次不迁移或清除已有字体记录。

`+29` 界面移除远处的文字 `×` / `✓`，仍可通过 `Esc` 取消，撤销和删除入口保持可用。控件采用紧凑样式；三个控制点显示为 28 逻辑像素，同时保留 44 逻辑像素的触控区域。

选中文字后，用三个控制点调整布局：移动控制点改变位置；缩放并旋转控制点同时调整文字大小与角度；宽度控制点只调整换行宽度。文字框随内容紧凑排布。屏幕底部输入时，编辑区域会随软键盘出现临时移到可见范围，保存或取消后恢复原来的阅读视图；实际 iPad 键盘效果仍待真机验证。

`+29` 旋转接近 0°、90°、180° 或 270° 时，进入目标角度 4° 范围会吸附对齐，偏离超过 7° 才脱离，便于稳定放正。旋转手势期间显示细横纵虚线辅助对齐，手势结束后收起。

**`0.8.10+30` 批注布局候选：** 三个文字控制点靠近文字框边缘布局，保留 44 逻辑像素触控区域，并避开正文、彼此和键盘。画笔与文字使用相同的固定 28 逻辑像素色点，选中状态使用独立的 36 逻辑像素外圈，不挤小颜色点。该布局已完成定向检查和合成截图审阅，真实触控体验仍须以装机验证为准。

`+30` 仅新建文字草稿以短框起步，正常缩放时约为纸面 90–120 逻辑像素。输入后按实际文字长度增长，达到页面宽度 30% 与当前可见宽度 33% 两者中较小者后换行，不改变字号。手动调宽或缩放后，宽度按手动结果保持，不再随输入自动增长；已有文字的保存宽度不改。

批注绑定曲谱条目、内容版本和页码，保存在应用数据目录。页面与批注使用同一缩放变换，源 PDF 和图片不会被重写。

遇到未保存或保存失败提示时，保留当前应用，检查空间后重试，再切换或同步。不要通过卸载或清空数据解决保存失败。

外部替换曲谱后，旧批注仍属于旧版本，不直接套用到新版。重新打开新版本前确认是否仍需要旧版资料。

## 6. 曲单

进入“曲单”创建排练或演出清单，添加曲谱并拖动排序。同一首可重复出现，每次出现有独立条目身份。

一首末页继续下一页进入下一首首页，首页上一页回到上一首末页，整张曲单首尾不循环。曲谱缺失或未准备好时保留当前位置并提示，不自动跳过。

创建曲单不代表文件已下载。出门前准备所需内容，在离线状态逐首检查。

## 7. 同步批注与曲单

两端连接后同步阅读资料。同一对象被两端分别修改时可能冲突，应用保留双方版本，在“保留的冲突版本”中查看。

当前没有完整的选版解决流程，看到版本不等于冲突已解决。演出前尽量先同步，再集中在一台设备编辑，最后同步回另一端。

## 8. 更新、签名与备份

iPad 更新保持原 Bundle ID 和签名身份，先备份后覆盖安装。续签更新签名有效性，不会自动升级应用代码。

iPad 可显示从已安装应用描述文件解析的到期时间，无法解析则显示未知。电脑显示设备上次报告及接收时间，不能据此判断实时在线或续签成功。

Windows 的固定启动器与版本目录分开，安装流程见 [固定启动入口](../tools/windows/README.md)。更新入口不会自动关闭正在运行的旧程序；保存后自行重开。

原谱、应用数据和离线副本作用不同：原谱备份不能替代批注与曲单备份，离线副本也不是应用完整备份。项目暂不承诺一键备份恢复。
