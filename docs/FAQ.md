# 常见问题

[返回首页](../README.md) · [使用指南](USER_GUIDE.md) · [构建文档](BUILDING.md)

## iPad 找不到电脑或连接失败

确认电脑阅读器已打开并显示连接二维码，两端位于同一局域网，iPad 已允许本地网络权限。访客 Wi-Fi、客户端隔离、VPN 或防火墙可能阻断设备互访。不要为排查关闭全部防护；检查对应应用在可信网络的访问权限。

电脑切换网络后更新二维码，再重新扫描。`127.0.0.1` 只指当前设备，`0.0.0.0` 是监听地址，都不是 iPad 应填写的电脑地址。

## 二维码或配对码失效

配对码两分钟内单次有效，多次失败或已使用后需重新生成。校准电脑与 iPad 的时间，扫描阅读器显示的新二维码，使用应用内扫码入口。

## 目录看得到，曲谱却打不开

目录同步与文件下载是两步。检查该条目是否已下载、是否等待更新，以及设备剩余空间。选中曲谱或文件夹下载，等完成后再离线打开。

如果电脑原谱本身无法读取或只是云盘占位文件，先在电脑补全文件、刷新谱库，再同步。加密、损坏或不受支持的文件应先用其他阅读工具检查。

## 同步中断会从头下载全部文件吗

重试会尽量复用已核验完整文件；单个未完成文件需要重传。上次成功提交的清单在失败时保留。达到总文件数仍可能在提交清单，以完成提示为准。

## 离线文件怀疑损坏怎么办

在同步界面使用“完整校验已下载文件”。校验会重新读内容，较普通打开耗时更长；发现问题后保持电脑源文件可读，重新同步。不要先卸载应用或清空全部数据。

## 批注会写回 PDF 吗

不会。批注、文字、曲单与阅读位置在应用数据目录中，原谱保持只读。目前没有承诺把批注导出为已嵌入标记的 PDF。

## 换了同名 PDF，旧批注怎么没贴过来

批注绑定内容版本。替换内容后即使文件名相同，也不把旧笔迹直接套用到新版，避免页数或排版变化造成错位。保留旧版与应用数据，不要通过覆盖状态文件强行迁移。

## 发生批注或曲单冲突怎么办

打开“保留的冲突版本”查看双方内容。当前没有完整选版解决流程，显示一个代表版本不等于另一版本已丢弃或冲突已解决。重要编辑前先同步，尽量减少同时改同一对象。

## 脚踏不翻页或一次跳多页

确认脚踏实际发送 `Page Up` / `Page Down`，阅读器拥有焦点且不在文字输入框中。本应用忽略按住的重复事件，其他脚踏映射或第三方转换工具需要单独验证。反馈时提供键位设置和单次按下的表现。

## Windows EXE 拿到另一台电脑无法运行

保留整个 Release 目录，包括 DLL、`data/` 和原生资产。检查目标是 Windows x64，并安装所需运行环境；用 `flutter doctor -v` 检查开发环境。不要只复制 EXE。

## Windows 插件链接报错

若 `pub get` 已完成依赖解析，只在插件链接阶段失败，可运行 `tool/prepare_windows_links.ps1`，再使用 `--no-pub` 构建。它不是依赖下载失败的修复工具，详见 [构建文档](BUILDING.md)。

## 更新后开始菜单或任务栏仍启动旧版本

普通构建不会切换固定入口。按 [Windows 部署说明](../tools/windows/README.md) 发布完整版本目录，保存后关闭旧窗口再重开。固定启动器的 `--verify` 可只读核对部署；不要移动或删除当前指针引用的版本目录。

## IPA 下载后无法直接安装

Releases 中的 `unsigned` 包未签名，需本地签名安装。先校验 SHA-256 并核对 `build-info.txt`。未签名容器存在不代表已签名或支持直接点开安装。

## 到期时间未知，或电脑日期没有立即变化

未发现可支持的描述文件时显示未知。到期时间是尽力解析的显示信息，不是签名真实性或撤销检查。电脑保存的是最近收到的历史报告，网络断开时不会自动获得新状态。

续签与应用升级不同，阅读器也不能代替签名工具确认后台刷新或未来续签成功。重要资料先备份，更新保持原身份和 Bundle ID。

## 数据在哪里，能否当成备份

索引、阅读状态、同步设置和离线副本保存在应用支持目录，不放进源谱库。原谱备份不包含批注，离线副本不等于整个应用备份。项目暂不提供一键备份恢复承诺。

## 如何提交有用的问题反馈

提供平台、系统版本、应用版本或 Git 提交、复现步骤、预期与实际结果。尽量使用最小合成文件；发布截图前遮住个人路径、曲谱内容、二维码和账号。不要上传真实配对凭据、描述文件或私人批注。
