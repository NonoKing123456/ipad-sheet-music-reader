# 0.8.10+41 正式更新

Windows 正式启动入口及两端本地分发包均已更新。

## 本轮修改

- 文字选中时只保留一条编辑、复制、删除操作条，输入时切换为取消、完成。Windows 文字按钮缩小；移动、宽度、缩放旋转使用紧凑圆形图标。
- 缩放旋转手柄按比例改变字号、文字宽度及选框宽高；上方字号数字同步。右侧宽度手柄仍独立调整换行宽度。取消及撤销恢复正确数值。
- 批注模式未选工具时，点击已有文字会同时选中文本框和文字工具；首次点击不打开输入框，也不误翻页。阅读模式与已选画笔不触发此联动。
- iPad 批注独立进入，中央点击仅显隐阅读栏；工具与样式单行排列，横向颜色、单个取色入口及拖动大小按钮。
- 阅读页与文件浏览页增加加入曲单入口，共用多选、新建和重复添加保护。

## 验证与交付

- Windows 与 iPad 模拟的文字点击联动测试通过；字号、等比例缩放、取消、撤销、文字编辑及工具切换相关回归通过。最新改动静态分析无问题。
- Windows Release 编译成功，新构建可启动；19 个发行文件、ZIP 字节和正式启动器指向均验证通过。最后的窗口自动操作由用户按 Esc 停止，没有继续点击。
- iPad [run27](https://github.com/NonoKing123456/ipad-sheet-music-reader/actions/runs/41647490904) 构建成功。源码提交 `2685fa63b95cb823c15f8514d6359719d69e0ecf`，117 项生产输入与 Windows 使用同一冻结源码。
- iPad 图像解码、签名日期、后台队列及存储检查通过；下载资产摘要、ZIP CRC、设备版本及包内 6 个 arm64 / IOS 二进制通过验证。
- Windows 分发包：`曲谱阅读器-Windows-0.8.10+41.zip`，解压整个目录后运行 `score_reader.exe`；本机已有快捷方式直接使用新版，旧进程需退出重开。
