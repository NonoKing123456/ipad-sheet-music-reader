# 0.8.10+58 更新

- iPad 翻页后，短暂显示与阅读界面字体一致的页码。全屏演奏时只保留谱面。轻点中央打开工具栏，即可查看曲单、定位当前曲目，或直接切换到另一首。
- iPad 目录把文件类型与页数排在一起，为长曲名留出更多宽度。搜索支持一键清除，并显示当前搜索范围。
- 优化谱库导航、目录编辑和曲单管理，支持删除整张曲单。Windows 的谱库操作菜单更清楚地标出作用范围。
- 可以单独移除损坏的离线副本，保留电脑原谱。取消整个谱库或文件夹的自动下载后，已经下载的谱面仍可阅读。
- 改进最近阅读记录的恢复、批注重试与分享，以及同步状态和搜索结果的反馈。

Windows 使用 x64 安装器。iPad 提供未签名 IPA，可用原 Apple 账号通过 Sideloadly 覆盖安装。
