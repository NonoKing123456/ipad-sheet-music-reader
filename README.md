# iPad Sheet Music Reader

Source-only application repository for **0.8.5+18**. Personal scores, annotations, set lists, credentials, private probes, preview fonts and build outputs are excluded.

Large-library browsing uses indexed entries and folders, virtual directory rows, and caches that change with metadata rather than each UI action. Ready files retain source-path, metadata, known-hash and publication checks without catalog write locks. Cold preparation runs in a worker, publishes one guarded entry patch, and coordinates with background scans; Windows opening and iPad HTTP preparation share that path. A cold file can still require one full catalog read/write. Authenticated paged catalogs and existing download selections remain compatible.

Windows uses one reader for library opening, startup paths and the file chooser. It starts in reading mode, with explicit annotation, a compact toolbar, and single, double or true continuous views. Double-page grouping offers first-page-alone or paired pages and remembers the choice per library entry. Each paper displays its own ink and text; editing focuses the selected page and returns to its spread or continuous anchor. Wheel scrolls continuously, Ctrl+wheel zooms, and rendering keeps at most four high-resolution papers. Center taps hide or restore the toolbar; top-edge hover temporarily reveals it without fitting the paper again. Registered files retain their annotation identity; files outside registered roots are read-only and create no annotation or bookmark identity.

Update **both Windows and iPad together**, preserving the bundle ID and local signing identity. Do not uninstall or clear data. ReaderState schema 3 reads schema 1/2 ink without changing geometry, IDs, tombstones or layer order and adds typed vector text. The explicit T tool supports Chinese, English and punctuation with touch, pen or mouse; other touch remains page input. Incompatible state exchanges are rejected before peer/state changes, while existing schema 2 pending exchanges can resume. Annotation storage and merge semantics are unchanged in this release.

Large iOS images retain serialized ImageIO downsampling and resource leases; visible foreground readers request wakefulness. Original scores are never rewritten. Prior shared-core synthetic macOS ImageIO smoke passed, but this release's final iOS build has not run at source preparation time. Local JIT timing does not establish release performance or iPad frame rate; a first-open transient pause remains unassigned. Physical iPad input, pedal, wake and memory behavior still need hardware feedback.

The unsigned workflow fixes Flutter **3.47.8**, public standard **macos-26** and Xcode **26.6**, runs the existing production-core synthetic ImageIO and storage smoke checks, then verifies **IOS / arm64**. Only the unsigned IPA, checksum and build information are published as a prerelease. Local signing is required. No Apple credentials or private scores are uploaded. Keep the exact allowlist and free runner; workflow-path pushes trigger builds, and owner manual dispatch requires `public_source_confirmed`.
