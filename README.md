# iPad Sheet Music Reader

Source-only application repository for **0.8.9+22**. Personal scores, annotations, set lists, credentials, actual provisioning profiles, private probes, preview fonts and build outputs are excluded.

The iPad home shows the expiration from its installed bundle's embedded profile. A bounded Foundation parser extracts the CMS-contained XML/binary plist date; missing, malformed or unsupported formats show unknown. This is best-effort display metadata, not CMS signature or revocation verification. Only status and UTC milliseconds cross to Dart or the paired computer. No profile, certificate, Apple account or device identifier is transmitted or stored.

Windows shows the paired iPad's historical report with the computer's confirmation time in details. A separate optional authenticated status endpoint accepts at most 1 KiB; identity comes from the existing bearer peer and receipt time from the server. A small leased, serialized, atomic store filters by the current server and still-authorized peers. Offline reports remain labelled as historical; unknown reports retain an explicitly marked last-known value. Reports coalesce to the latest pending value, use only bounded existing-tick retries and never start a catalogue or annotation exchange. A legacy server's 404 degrades silently.

Update both apps to enable the Windows mirror. The schema 3 annotation protocol and old ink/text/layer semantics are unchanged and remain wire-compatible with 0.8.5. Sideloadly on the computer handles automatic refreshing when the iPad is visible; renewing does not install a product update. This app does not confirm daemon configuration, current online status or a successful renewal. Actual installed-profile reading and physical renewal remain unverified at source preparation time.

The previous indexed large-library browsing, worker preparation, bounded raster decoding, single/double/continuous Windows reading and per-page annotations are retained. Original scores are never rewritten. Local tests and synthetic screenshots do not establish iPad hardware behavior.

The workflow fixes Flutter **3.47.8**, public standard **macos-26** and Xcode **26.6**. It retains the ImageIO/storage smoke checks and adds 15 synthetic checks using the production signing-expiry parser, with stdout in build information. Those new native checks and this release's iOS build have not run at source preparation time. The device build verifies **IOS / arm64** and publishes only an unsigned IPA, checksum and build information as a prerelease. Local signing is required; no Apple credentials or real profiles are uploaded. Keep the exact allowlist and free runner.
